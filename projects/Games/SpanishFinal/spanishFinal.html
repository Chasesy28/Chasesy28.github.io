Instructions

Puede usar WASD o las flechas para moverse. Puede usar la tecla de W, la tecla de espacio, o la flecha hacia arriba para saltar. Puede usar la tecla de A o la flecha hacia la izquierda para moverse a la izquierda. Puede usar la tecla de D o la flecha hacia la derecha para moverse a la derecha. Puede usar la tecla de S o la flecha hacia abajo para moverse hacia abajo a través de los plataformas delgadas. Puede usar la tecla de E para interactuar con los objetos, como ejemplo, los carteles.
